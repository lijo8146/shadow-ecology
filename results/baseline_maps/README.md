# Baseline map package 0 — acquisition-ready

No data-derived baseline map has been created yet: the required imagery and
hydrography inputs have not been downloaded and checked. This package freezes
what the first public-data baseline atlas must contain and prevents a
schematic or unverified map from being presented as an analytical result.

Create the package only after the coverage checks in `data_inventory.md` pass.
Use `baseline_map_spec.yaml` and write the completed source/processing details
to `map_manifest.csv`. Maps that identify priority areas on or immediately
adjacent to Tribal lands or waters require the release workflow in
`governance_boundary_register.md`.
